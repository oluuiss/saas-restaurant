# Lumenu

SaaS para restaurantes: cardápio digital, delivery, reservas de mesa, promoções e disparo de email.
Cada restaurante ganha um site próprio, editável direto na tela, e um painel para o dia a dia do salão:
mesas, pedidos, equipe e financeiro.

## Banco de dados

[Neon](https://neon.tech) (PostgreSQL serverless). A conexão é feita pela variável `DATABASE_URL`, no arquivo `.env.local`.

## Rodando

```bash
npm install
```

```bash
npm run dev
```
